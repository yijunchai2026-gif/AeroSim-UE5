## 下批三种代表形体规格（尚未实施）

沿用 QA_PLAN 中三种现有 archetype 名称，先通过实际实例 ID/transform/bounds 确认采样对象；不能单凭截图把某棵树认作特定模型或正式物种资产。

1. `CoastalFloraFirMatureA`：打破同高水平叶层。主枝从树干连续弯出，末梢下垂，叶簇围绕真实次级枝形成前后厚度，留出大小不一的天空孔；根部和主干连续收锥，避免细棍承托整张绿板。
2. `CoastalFloraPineMatureA`：保留区别于 fir 的开放上冠，少量可读、长短不等的弯曲承重枝，针簇集中在不等距端梢；减少整圈同角横杠，偏冠与缺枝由枝骨架形成，不能只随机旋转同一扁片。
3. `CoastalFloraOakA`：从较低处可读分叉与粗细层级建立宽冠，若干不等大的冠簇有前后深度和负空间，轮廓由支撑枝决定；禁止圆球、水平圆盘、整树 billboard，也不把代码名称当作正式橡树资产确认。

先只做三棵代表实例与约 30–50m 林缘/通道试段，保持总实例密度、正式资产身份和现行预算；重分配已有叶面，禁止再加数百万面。调整枝形可能影响包围盒、碰撞/飞行净空与 LOD，必须重测，不能只保存好看的单一相机。此次评审没有修改 flora 源。
